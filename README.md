# nonograma-legal

Páginas legais do aplicativo **Nonograma Picross** (Android, offline).

- Política de privacidade (pt-BR): https://lucas-azambuja.github.io/nonograma-legal/
- Privacy policy (English): https://lucas-azambuja.github.io/nonograma-legal/privacy.html

Páginas estáticas, sem JavaScript, sem rastreador e sem recurso de terceiro.

> Fonte canônica do texto: documento `politica-privacidade` (rev. 2). Qualquer alteração aqui
> precisa ser feita junto com o formulário de Data Safety do Play Console — divergência entre
> os dois é motivo de recusa.
