Política de Privacidade — Nonograma Picross

Última atualização: 17/11/2026

Esta política explica quais dados são tratados quando você usa o aplicativo Nonograma Picross ("o aplicativo"), desenvolvido por Lucas Azambuja.

Ela é escrita para ser lida, não para proteger quem a escreveu. Se alguma coisa aqui não estiver clara, escreva para lucas.azambuja@foregon.com.

1. O resumo, em quatro linhas

  • O aplicativo funciona sem internet e não tem conta, login nem cadastro. Não pedimos, não guardamos e não enviamos para lugar nenhum o seu nome, e-mail, telefone, contatos, fotos, arquivos ou localização precisa.
  • Seu progresso fica só no seu aparelho. Puzzles resolvidos, tempos e preferências nunca saem dele. Desinstalar o aplicativo apaga tudo isso.
  • O que sai do aparelho é dado de publicidade, coletado pelo SDK de anúncios do Google (Google Mobile Ads / AdMob) para exibir e medir anúncios. É o único envio de dados que acontece.
  • Se você comprar a remoção de anúncios, o SDK de anúncios deixa de ser inicializado e esse envio deixa de acontecer.

2. Dados que nós coletamos diretamente

Nenhum. Não operamos servidor, não temos banco de dados de usuários e não recebemos nenhuma informação sua.

3. Dados coletados pelo SDK de anúncios do Google

O aplicativo usa o Google Mobile Ads SDK (AdMob) para exibir anúncios. Esse SDK é operado pelo Google, que atua como controlador independente dos dados abaixo. O Google compartilha esses dados com seus parceiros de anúncio.

DadoPara quêVocê pode desativar?
Identificador de publicidade do Android (Ad ID) e App Set ID Exibir anúncios, medir desempenho, prevenir fraude Sim. Android → Configurações → Google → Anúncios → Excluir ID de publicidade
Endereço IP, usado também para estimar a localização aproximada (cidade/região) Entregar anúncio no idioma e mercado certos, prevenir fraude Não, é inerente à conexão. O aplicativo não pede permissão de localização e não acessa o GPS
Interações no aplicativo (abertura do app, toques no anúncio, visualização de vídeo) Medir desempenho do anúncio Não separadamente
Informações de diagnóstico (modelo do aparelho, versão do sistema, erros do SDK) Fazer o anúncio funcionar e diagnosticar falhas Não separadamente

Esses dados são transmitidos criptografados. O tratamento feito pelo Google é regido pela política do Google, não por esta:

  • Política de Privacidade do Google: https://policies.google.com/privacy
  • Como o Google usa dados de parceiros: https://policies.google.com/technologies/partner-sites

4. Anúncios: o que o aplicativo faz e o que ele nunca faz

Este aplicativo publica o próprio limite de anúncios, por escrito:

  • No máximo 1 anúncio de tela cheia a cada 2 puzzles concluídos.
  • Nunca menos de 90 segundos entre dois anúncios.
  • Nenhum anúncio nos 3 primeiros puzzles de uma instalação nova.
  • Nenhum anúncio dentro do puzzle. Nunca.
  • Vídeo, só se você pedir — sempre com um aviso antes, e dá para dizer "Agora não".

Um anúncio de tela cheia que você não pediu só pode aparecer num único momento: quando você volta de um puzzle concluído para a tela de seleção. Não há anúncio na abertura do aplicativo e não há banner em nenhuma tela.

Os vídeos são anúncios premiados (recompensados) e só acontecem se você tocar para pedir, com a recompensa dita antes — eles são a única exceção às linhas acima, e existem porque são escolha sua. Nada no jogo é destravado por anúncio: não há vidas, energia nem moeda.

Se você comprar a remoção de anúncios (compra única), nenhum anúncio de tela cheia volta a aparecer e o SDK de anúncios deixa de ser carregado.

5. Consentimento na Europa, Reino Unido e Suíça

Esta versão do aplicativo não está disponível no Espaço Econômico Europeu, no Reino Unido nem na Suíça. Quando passar a estar, mostrará, antes do primeiro anúncio, um formulário de consentimento operado pela plataforma de consentimento do Google (UMP), onde você escolhe entre anúncios personalizados e não personalizados — e poderá mudar essa escolha a qualquer momento em Ajustes → Opções de privacidade.

Até lá, nenhum formulário de consentimento é mostrado, porque o aplicativo não é distribuído nessas regiões.

6. Compras

A compra de remoção de anúncios é processada pelo Google Play Faturamento. Nós não recebemos, não vemos e não armazenamos dados de pagamento — nem cartão, nem nome, nem endereço. Recebemos do Google apenas a confirmação de que a compra existe, e guardamos essa confirmação localmente no seu aparelho. O tratamento do pagamento é regido pelos termos do Google Play.

7. Crianças

Este aplicativo não é direcionado a crianças menores de 13 anos e não é distribuído no programa Google Play Famílias. Não coletamos conscientemente dados de crianças. Se você acredita que uma criança usou o aplicativo e algum dado foi tratado, escreva para lucas.azambuja@foregon.com.

8. Seus direitos (LGPD, Lei 13.709/2018)

Como não mantemos nenhuma base de dados sua, não há o que corrigir, exportar ou excluir do nosso lado. Na prática, seus direitos se exercem assim:

9. Retenção

Nós não retemos nada, porque não recebemos nada. Os dados locais ficam no aparelho até você apagá-los. A retenção dos dados de publicidade é definida pelo Google.

10. Mudanças nesta política

Se esta política mudar, a data de "última atualização" no topo muda junto e a versão nova fica nesta mesma URL. Mudança que altere materialmente o tratamento de dados será anunciada nas notas de versão do aplicativo.
